# 核对能力口径

本页说明 `hecha` 包对合成演练资料的核对规则。全部工程内容为合成演练，输出不构成真实工程放行依据。

## 对象与范围

- 段有桩号区间与上下游；接头是独立对象，区间端点的同一接头只是一处对象。
- 每段的核对元素：管段本体 + 每个接头处的本侧接口。报告覆盖到接头，不表示检查后来接上的另一侧接口；接口覆盖只计明确点名的接头（“含J50”“J50两侧接口”“只对X复测”）。
- 旧号经改号登记映射到现段号；重编号不改变原试验范围，未施工的改号不让旧证据失效。
- 报告的排除范围（如“不含支管B”）永远保留，任何汇总不得删掉除外。

## 证据失效与不得拼接

- 切断重接、接入、新增施工只让受影响的局部证据失效；明确“未施工”的段不受影响。
- 不同日期且中间改过接头的报告不能拼成一次完整试验：施工前的覆盖对受影响元素直接失效，不参与拼接。
- 计划、执行、完成、转述严格分开：计划与转述不作执行证据；转述/主张须与证据核对（如“全线无渗漏”对每段试压核对），不能因来源有引用便把转述当独立观察。
- 未记时间或流量保持缺失，不能从“冲洗完成”“充分冲洗”猜数值。

## 验收约定与结论

约定含数值、同时成立的工序与排除范围（本演练为 AC1 试压、AC2 冲洗、AC3 隔离）。每项结论为：

- 满足：证据齐全且参数达标；
- 参数不全：数值未记或结果未记，可由监理办理解释确认补有来源的实测值；
- 明确不合格：记录显示不达标（含更正后的中断，累计时长不等于连续时长），只能重新执行，不能确认补救；
- 缺证据：无有效记录，需补充试验/冲洗/隔离。

参数不全与明确不合格给不同处理。

## 解释确认

监理可确认解释或补有来源的实测值，约束如下：

- 必须注明来源（如计时原表）；未观察时段不能凭确认补值；
- 不能覆盖已有记录值，不能重复确认同一参数；
- 不能确认已明确不合格的记录；
- 适用范围不得超出原记录（如“仅适用L2A1”）。

## 局部签认与移交

- 可按具备独立边界的区段签认并局部移交；同批多段时，批内共用接头视为批内边界。
- 共用接头或上游隔离不满足时不能签认：相邻未验段须有有效隔离，否则不能留给运维猜。
- 多个移交段共享必要检查；检查被撤回时，按“撤回后结论由满足退化”找出真正依赖它的签认。撤回只作标记，原文保留。

## 交接后事项

- 运维接管后登记的冲洗、改接、复测作为新记录追加，参与同一套核对。
- 新施工使待交接局部重验；已签收依据仍原样可查。
- 已接管区段受变更影响时产生停用待确认事项，历史签收不改写、不能改成从未通过。
