# 饮水工程施工记录与验收条件的语义核对

项目保存用于本地业务联调的合成原始文本、对象登记及已有办理记录。文字包含尚未确认的主张，不能直接当作业务结论。资料口径见 [资料口径](docs/materials.md)，核对规则与能力见 [核对能力](docs/capability.md)。

`data/case.json` 是一份可追加原文的资料包；`hecha` 包提供可反复办理的中文语义核对：读施工记录、试验报告及验收约定，供监理确认事实、验收员判定覆盖、运维领取真正可接管的部分。全部工程内容为合成演练，本工具不自动放行真实工程。

使用 Python 3.11 或更新版本，无第三方运行依赖。

## 办理入口

```sh
# 移交查询：每段原句证据、具体缺项、相邻段为何不能搭便车、交接后未结事项
python3 -m hecha 查询 [--段 L2A2]

# 录入：校验资料并追加新记录（运维接管后登记冲洗、改接、复测同此）
python3 -m hecha 录入 --编号 WA-T3 --种类 pressure-test --原文 "八月六日J100两侧接口及B试压0.8MPa连续30分钟，无渗漏。"

# 解释确认：监理补有来源的实测值；未观察时段不能确认
python3 -m hecha 确认 --针对 WA-F1 --参数 连续时长 --值 22 --来源 计时原表 --适用 L2A1

# 局部签认：按具备独立边界的区段签认，可同批多段
python3 -m hecha 签认 --段 L2A2 B

# 撤回检查：找出真正依赖它的签认
python3 -m hecha 撤回 --记录 WA-R1 --理由 "原表遗失待核"
```

办理过程（追加记录、确认、签认、撤回）只追加写入 `data/journal.json`，原文不删改；可用 `--case`、`--journal` 指定其他路径。

运行检查：

```sh
python3 -m unittest discover -s tests -v
```

`tests/test_materials.py` 验证资料可读取、编号与引用有效；`tests/test_capability.py` 与 `tests/test_cli.py` 核对业务能力（证据失效、不得拼接、参数不全与明确不合格的区别处理、确认约束、局部签认边界、撤回依赖、交接后事项）。
